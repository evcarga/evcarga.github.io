# EvCarga Ecuador

Sitio de cargadores para carros eléctricos (Astro + Supabase), publicado en https://evcarga.github.io/

- `npm install` · `npm run dev` (desarrollo) · `npm run build` (genera `dist/`)
- Páginas: `src/pages/` (index, admin, privacidad, cargadores por ciudad)
- Publicación automática con GitHub Actions al subir a `main` y una vez al día.
- Nota: la base solo acepta peticiones con origen https://evcarga.github.io, así que en local la lista de cargadores no carga.
